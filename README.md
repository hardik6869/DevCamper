# DevCamper API

> Backend API for DevCamper application, which is a bootcamp directory website.

## Usage

Rename "config/config.env.env" to "config/config.env" and update the value/settings to your own.

## Install Dependencies

```text
npm install
```

## Run App

```text
# Run in Dev mode
npm run dev

# Run in Prod mode
npm start
```
